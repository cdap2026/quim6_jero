# Examen Interactivo de Química - 6° Grado

Este repositorio contiene una aplicación web interactiva en un solo archivo HTML diseñada para evaluar conocimientos sobre Sustancias Puras, Mezclas y Compuestos Orgánicos para el área de Química.

## Características y Ajustes de Inclusión
* **Accesible y Visual:** Creado con un diseño intuitivo, tipografía clara y grandes imágenes de referencia para favorecer el entendimiento de estudiantes con hipoacusia o leve déficit cognitivo.
* **Configuración Abierta:** Sin bloqueos de pantalla completa ni restricciones de cambio de pestaña, para disminuir la ansiedad durante la prueba.
* **Duración:** 45 minutos medidos mediante un temporizador integrado.
* **Libre Navegación:** El estudiante puede avanzar y retroceder por las 10 preguntas (8 cerradas tipo prueba Saber y 2 abiertas) libremente.
* **Exportación PDF:** Reporte automático del intento completo con calificación parcial e integración del banner institucional.

## Instrucciones de Despliegue en GitHub Pages
1. Inicia sesión en tu cuenta de [GitHub](https://github.com/).
2. Crea un nuevo repositorio público.
3. Sube el archivo `index.html` a la raíz del repositorio.
4. Ve a la pestaña **Settings** > **Pages** del repositorio.
5. En la sección "Build and deployment", selecciona la rama `main` y dale a guardar.
6. Espera un par de minutos; GitHub te generará un enlace público listo para compartir con tus estudiantes.
